CraveCart – Food Delivery Platform

CraveCart is a full-stack food delivery application built using the MERN stack (MongoDB, Express.js, React.js, Node.js) with real-time communication powered by Socket.IO.

The platform connects restaurants, customers, and delivery personnel in a seamless ecosystem:

For Restaurants:

Secure login and account management.

Add, update, and manage food menus.

Track incoming orders in real time.

For Customers:

Browse restaurants and food items.

Place orders with a smooth checkout experience.

Receive instant order updates (confirmation, preparation, dispatch).

For Delivery Persons:

Register and join the platform.

Accept and deliver assigned orders.

Real-time tracking of delivery status.

Key Features:

Authentication & Authorization: Secure login for restaurants, users, and delivery partners.

Order Management: Real-time order updates using Socket.IO.

Responsive UI: Built with React for a modern, mobile-friendly interface.

Database Management: MongoDB for storing users, restaurants, menus, and orders.

Scalable Backend: Node.js + Express.js for APIs and business logic.

Real-time Updates: Order status changes (placed → prepared → out for delivery → delivered) broadcast instantly.

CraveCart is designed to be efficient, scalable, and user-friendly, providing a smooth online food ordering and delivery experience for all stakeholders.
